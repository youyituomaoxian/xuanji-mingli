## 抓取注意事项（给下一次执行的人）

- jsDelivr 各节点（cdn/fastly/gcore/testingcf）**可能对中文内容做转码**，
  抓取后必须校验：① 无 `\uFFFD`；② 含书名关键词（如「紫微」「斗数」）；
  ③ 文件尾部为完整句（非截断）。校验不过换节点重抓。
- `raw.githubusercontent.com` 直连在本机不可用（TLS 证书链被干扰），
  需走镜像（ghproxy 系），但镜像有频率限制（403），宜以 jsDelivr 为主。
- GitHub 仓库大文件路径先经搜索/API 确认，不要猜路径。
